# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a suspected vulnerability in this repository.

Report security concerns privately to:

**alizadaemil404@gmail.com**

Include:

- affected module
- impact
- safe reproduction steps
- suggested mitigation, if known

## Scope

The Python package, CLI behavior, parsing logic, network input validation, CI configuration, and dependency configuration are in scope.

This is a defensive portfolio / learning project.

Do not use the toolkit to assess systems you do not own or have explicit authorization to test.
